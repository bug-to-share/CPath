# 审阅内容 原始审稿意见

来源：用户提供的 Codex 模型审稿意见；公开副本省略私有会话链接。

以下保留该会话最终答复；其中本地文件引用已规范为文件名。

**审稿结论：建议大修，当前版本不宜直接投稿。** 研究问题有价值，稿件也较诚实地披露了局限；但患者独立性、诊断参考标准和外部队列构成尚未核实，直接影响结果可信度。这些问题需要补充记录和重新分析，不能仅靠增加讨论中的限制声明解决。

我已审阅全文18页及图表。审阅对象：`MALT_SS_manuscript_v7_5.pdf`。本次提供的材料不包含文中引用的补充材料、逐切片预测表和源代码，因此以下意见基于正文及图表，不代表完成了原始数据复现。

论文的优点是临床问题明确，并报告了配对模型比较、简单基线、类别不平衡影响及采样波动；同时，没有把热图直接解释为病理机制，也没有声称已经证明优于病理医生。**当前最能成立的定位是探索性、回顾性分类研究。**

1. **患者级独立性未验证，是首要问题。**  
   位置：第2、13、15页。

   193张内部切片按切片划分训练集和验证集，未按患者分组。如果同一患者的不同切片、连续切片或不同染色进入不同分区，内部性能可能被高估。外部152张MALT切片对应多少患者也未知，不能将切片数量等同于独立病例数量。

   **修改要求：**建立患者—标本—蜡块—切片对应关系，核查分区内及分区间重复，报告各组患者数和每位患者切片数。若存在交叉，须重新划分并训练；若存在一人多片，应采用患者聚类重采样，并明确患者级结果如何汇总。目前不能断言已经发生泄漏，但也不能排除。

2. **参考标准和病例谱缺失，尚不能确定模型究竟在区分什么。**  
   位置：第2、13页，Table 1。

   文中说明MALT和SS是记录中的切片标签，并区分了MALT患者的SS病史，这一点合理；但仍未报告实际确诊流程、复核者、辅助检查和疑难病例处理方法。引用疾病分类标准不能替代描述本研究实际采用的参考标准。

   **修改要求：**补充诊断判定流程、复核人数与资历、分歧处理、使用的免疫表型或分子证据，以及SS组的纳入依据。尤其应列出唾液腺部位、活检/切除方式和标本大小，排查模型是否主要利用组织部位或取材差异。若只研究两个经过筛选的诊断组，结论应严格限定于该病例谱。

3. **外部染色与来源混杂，削弱了主要验证结果。**  
   位置：第5–7、13页，Figure 3。

   外部152张MALT中，111张被归为“IHC/特殊染色标签”，占73.0%；但该归类部分依据文件名及剩余类别分配，不能视为真实染色鉴定。16张SS的染色也未确认。因此，当前数据无法区分疾病信号、染色信号和来源差异。

   更关键的是，剔除这111张后，敏感度由93.42%降至75.61%，所有10张MALT假阴性均来自H&E-like组。作者已经披露了这一点，但它应当影响主要结果的定位。

   **修改要求：**逐片核实染色及标本来源。如果目标是H&E辅助诊断，应以核实后的H&E队列为主要评估对象；混合染色分析作为补充。仅做现有事后剔除，不能建立“H&E外部验证”。

4. **外部病例筛选过程不透明，存在选择偏倚风险。**  
   位置：第2、13页。

   外部材料从227张变为223张成功预测，再变为168张纳入分析。成功预测后排除55张，占223张的24.7%，但排除标准和人工审核流程尚未定稿。

   **修改要求：**提供完整流程图，分别说明4张预测失败和55张排除的原因、诊断类别、患者数、审核时间，以及审核者是否看到模型分数。若部分排除属于合理的数据清理，应给出可复核依据，并进行适当的敏感性分析。目前不能认定存在选择性排除，但缺少这些信息就无法评估其影响。

5. **内部验证反复参与选择，现有外部数据也不能视为全新的确认性测试。**  
   位置：第3–4、12、14–15页。

   49张内部验证切片用于选择训练轮次，并支持模型、集成和阈值比较。固定预测值的bootstrap区间不能涵盖这些选择带来的不确定性。正文又说明，后续开发已知晓历史外部结果，因此冻结一次新分析方案，并不能恢复外部队列的完全独立性。

   **修改要求：**补充开发与评估时间线，明确哪些选择发生在查看外部结果之前。患者链接确认后，可采用患者分组的嵌套交叉验证改进开发阶段评估；确认性结论仍需要从未参与开发决策的测试材料。这里的问题并非必须另设一个“内部测试集”，而是目前缺少可信的独立确认性评估。

6. **复杂模型的增益尚未建立，需要重新聚焦创新性。**  
   位置：第3–4、7、12、14页。

   Hybrid相对ABMIL的内部AUROC差为0.0100，95% CI为−0.0184至0.0452；外部差值区间也包含零。简单均值特征逻辑回归的外部AUROC达到0.8335或0.8462。此外，模型间训练预算、维度和实现完整度不同，不能将差异直接归因于聚合架构。

   **修改要求：**优先保留少量、实现可靠且训练条件可比的基线，补充多训练种子和有针对性的组件消融，例如均值分支、原型统计量、区域分组及学习门控。重复抽取20个输入bag不能替代重复训练。若仍未发现稳定增益，应突出疾病任务的探索价值，降低方法优越性主张。不能把“未证明差异”解释为模型等效。

7. **读者实验尚不具备正式比较条件。**  
   位置：第7–9页，Table 4、Figure 4。

   两位病理医生只有待核实的汇总计数，缺少逐病例判断、经验、盲法和阅片条件；模型又在这些切片上进行过选择。作者虽未声称优于医生，但主文中的排名、加粗和并排柱形图仍容易传达这种印象。

   **修改要求：**取得完整记录后再报告配对比较。若无法补齐，建议删除主文Table 4和Figure 4，或将核实后的描述性结果移至补充材料。如果要证明AI辅助效益，需要另行设计有无AI辅助的阅片研究，当前汇总数据不能支持该结论。

8. **Figure 5需要强化质量控制，尚不能作为病理可解释性证据。**  
   位置：第8、10页。

   Case 10的最低margin窗口视觉上几乎为空白；正文报告其分割轮廓覆盖率为48.11%，但轮廓覆盖不等于真实组织含量。这提示分割、patch筛选或坐标映射需要进一步核查，不能仅凭裁剪像素匹配证明所选区域具有诊断意义。

   **修改要求：**保留该失败实例，核查真实组织比例、坐标对应和背景patch比例；请病理医生盲法评价选区，并与随机区域比较。主要解释图最好使用与主预测相同的bag。全部217个参考bag中均值分支门控系数最大，是值得研究的现象，但不等于该分支贡献最大，仍需消融验证。

我根据正文混淆矩阵复算了主要阈值指标，**未发现这些指标的明显算术错误**。但展示重点需要调整：

| 核查项目 | 结果 | 审稿判断 |
|---|---:|---|
| 外部模型准确率 | 153/168＝91.07% | 全部判为MALT也有90.48%，仅净多判对1张 |
| 外部特异度 | 11/16＝68.75% | 仅16张SS，每改变1张就变化6.25个百分点 |
| 外部阴性预测值 | 11/21＝52.38% | 当前样本结果不能支持排除诊断用途 |
| 排除特殊染色标签后的敏感度 | 31/41＝75.61% | 应与整体敏感度同等突出展示 |
| 外部AUPRC | 文中报告0.9733 | 阳性比例已达90.48%，需要同时展示基准线 |

这些判断不意味着模型毫无区分能力：AUROC反映的是另一层面的排序表现。但高准确率、AUPRC或PPV不能单独证明临床实用性，且本队列的预测值不能直接外推至其他患病率的人群。
