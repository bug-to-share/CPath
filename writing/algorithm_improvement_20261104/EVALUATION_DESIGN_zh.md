# 算法改进实验：评价、选择与独立核验方案

日期：2026-11-04。本文负责评价设计，不构成已获得性能提升的结论。最终执行配置应另存为机器可读清单，并在外部结果解封前冻结。

## 1. 本轮能回答的问题

在现有 UNI2-h 特征、原始 144 张训练切片 / 49 张内部评价切片以及相同训练预算下，哪些算法改动能够提高内部区分能力、改善随机种子稳定性，并在历史外部队列上保持合理的性能？

- 固定现有标签映射：MALT 为阳性，SS 为阴性；不引入 SP 类别。
- 不改变原始数据清单、标签或 144/49 划分；不重新打开作者已核查的问题。
- 168 张外部切片（MALT 152、SS 16）此前已被分析，本轮不能称为新的确认性外部验证。它是冻结改进方案后的历史外部再评价。
- 本轮只需要现有特征、checkpoint 和切片标签。医院持有的临床、患者、阅片、染色核查信息继续待补，本轮不补造这些内容。

## 2. 有限候选与配对实验

建议以 **10 个预定义配置 × 3 个种子（17、29、43）** 为首轮上限。下表是可实施的候选槽位；由算法调研和代码核查确定最终实现后，必须在训练前冻结，不要求机械执行尚无依据的候选。

| 配置槽位 | 目的 | 与基线相比的可识别改动 |
|---|---|---|
| B0：原 learned-gate 复跑 | 检验训练实现与历史 9-run 一致 | 完全复用历史受控训练设定 |
| B1：matched attention 复跑 | 判断复杂融合是否值得 | 复用历史简化模型 |
| C1：输入归一化 | 降低特征幅度依赖 | 明确写出 LayerNorm 或 L2 中的一种；不能暗中一起改变 |
| C2：训练集特征中心化 / 标准化 | 检验全局特征偏移敏感性 | 统计量只用 144 张训练切片拟合，保存参数 |
| C3：降低模型容量 | 减少小样本拟合不稳定 | 只改变投影 / 融合维度，报告参数量 |
| C4：加强正则化 | 降低训练变异 | 单一明确的 dropout 或 weight decay 设置 |
| C5：包级特征增强 | 增强对局部特征扰动的鲁棒性 | 明确掩码 / 噪声比例和作用位置 |
| C6：双 bag 一致性 | 降低切片抽样依赖 | 同切片两个独立训练 bag，固定一致性系数 |
| C7：软监督增强 | 增强小样本学习 | 单一固定的特征 mixup 或 label smoothing 方案 |
| C8：明确的聚合结构替代 | 研究结构改进 | 由文献与可用特征支持的一种聚合器，不能打包多个未控制的组件 |

候选可以被有依据的更适合方法替换，但不要把训练后临时调整隐藏为预先定义。若首轮不成功，应形成结果报告，再明确建立下一轮方案，而不是无限搜索并只保留赢家。有限搜索范围不意味着这些比较已足以给出组件因果归因。

### 对齐条件

1. 三个种子固定为 17、29、43，所有配置均运行，不因为结果较差而补种子或跳过种子。
2. 每个种子固定训练 bag 索引、epoch 内顺序与内部评价 bag；兼容的公共模型层使用相同初始张量。结构不同的层不能伪称“逐参数完全相同初始化”。
3. 默认沿用 30 epochs、batch size 8、AdamW、lr=5e-5、weight decay=1e-4、阳性 BCE 权重 77/67。候选改变的超参数必须是配置显式字段。
4. 仍采用“内部 AUROC 首次严格达到最高值”的 checkpoint 规则；并列不更新。保存最佳与最后 epoch，报告选择 epoch。
5. B0/B1 先做复现检查。若与旧实验偏差超过数值容差，先追踪特征、初始化、采样、软件或优化差别，再把原因记录进报告；不以改动后的基线冒充原协议复跑。
6. 双 bag 方法耗费额外前向计算，不能声称与单 bag 方法严格计算量匹配。报告 wall time、GPU time/峰值显存和参数量。

## 3. 候选选择必须只看内部结果

**主选择指标：固定内部评价 bag 上，三个训练种子的 AUROC 算术均值。**

- 按均值排序，三种子的全部数值同时显示。
- 如均值差 <0.002，按更低的种子间 sample SD 选择；仍相同则按参数更少、训练时间更短的顺序选择。
- 在外部推理之前保存 `selection.json`：候选全集、内部均值和 SD、选择规则、赢家 ID、所有 checkpoint 哈希、代码哈希、时间戳。
- 外部评价至少覆盖 B0、B1 与选出的改进方案，三种子均保留。预算允许时可在方案已冻结后统一评价全部候选，但必须明确：外部结果不触发重选，不用“外部最优候选”替换内部赢家。
- 若多个内部候选非常接近，选定一个并说明不确定性，不根据外部标签破局。

内部 49 张切片已用于每个 seed 的 epoch 选择，再用于方法选择；所以内部收益是开发阶段收益，不能直接视作独立泛化收益。这个限定不否定实验价值，也不需要重做作者已明确确认的原始划分。

## 4. 预定义成功标准

把“执行完成”“内部改进”“历史外部支持”分开，不强行保证三者都成立。

### A. 技术执行成功（必须）

- 计划中所有配置和种子均有完成状态或可追溯失败原因。
- 预测行数、切片 ID、标签、bag 索引及 checkpoint 选择可独立复算。
- B0/B1 复现没有未解释偏差；没有外部结果参与更新模型或选择方案。

### B. 有价值的内部改进（预设实用门槛）

- 相对 B0 的三 seed 平均内部 AUROC 至少提高 **0.01**，且至少 **2/3** 配对 seed 的 AUROC 不降低。
- 同时报告种子间 SD；如果均值提高而 SD 大幅增大，应称为“均值提高但稳定性未改善”。
- 固定 0.5 阈值下内部 balanced accuracy 若降低超过 **0.02**，标注为“排序改善伴随工作点退化”，不能概括成全面改善。
- 以上 0.01 和 0.02 是本轮工程判据，不是已验证的临床最小重要差异。即使未跨过门槛，仍完整报告真实结果。

### C. 历史外部支持（冻结后评价）

- 首先比较改进方案与 B0 的三 seed 均值和配对差异；再比较预定义的三 seed 均概率 ensemble。
- 若外部 AUROC 提升但 sensitivity 或 balanced accuracy 下降，明确呈现 trade-off。
- 原始历史主模型 AUROC 0.8721、固定工作点等只作为另一个有清楚 checkpoint 身份的参照。新模型不同 seed / 训练协议下的排序收益，不能与历史主模型最好的阈值指标拼接。
- 可以报告逐切片配对 bootstrap 的 AUROC 差值及区间；不得把“不跨零”包装成完全独立确认，因为这仍是已知外部队列上的探索性再评价。

## 5. 单 bag、多 bag、full bag 和多 seed ensemble 的区分

| 输出 | 定义 | 在本轮的角色 |
|---|---|---|
| 单 bag / 单 seed | 历史固定 512-row 评价输入，单个训练 checkpoint | 候选选择和历史受控比较的统一基础 |
| 多 bag / 单 seed | 同一 checkpoint 对固定 K 个 512-row bag 的概率均值 | 单独验证抽样稳定性；不等同于多个训练 seed |
| 单 bag / 三 seed | 三个 checkpoint 对同一历史 bag 的概率均值 | 预先固定的训练 ensemble，严禁取 max 或事后删 seed |
| 多 bag / 三 seed | 先每 seed 对 K bag 均概率，再对三个 seed 均概率 | 组合稳定性方案，必须给出全部计算成本 |
| full bag | 一次输入切片全部 token，必要时分块精确累计 attention | 另一个推理协议；只能单独标注为探索性输出 |

建议 `K=20` 与已有采样研究一致，明确固定 20 组评价 bag、所有模型共享。K 不根据外部性能挑选。若为控制成本使用 K=5，应在运行前固定，并与历史 K=20 分开显示。

对于有 max、方差、top-k、原型匹配或统计分支的模型，full bag 会改变输入数量和统计分布；不能把 full-bag 结果直接混入固定 512-row 比较。分块必须在数学上与完整聚合等价，不能把每块输出概率平均后称作 full bag。

同一 bag / seed 的输出概率平均与 logit 平均不是同一个方法。本轮默认概率平均，禁止看结果后在两者间择优。

## 6. 必须报告的实用指标

每个 cohort / 方法 / seed / 推理协议均报告：

- n、MALT / SS 数量、AUROC、average precision；外部 AP 的无信息基线是 152/168≈0.9048，应一并给出以避免被高患病比例误导。
- 0.5 阈值下 TP、FP、TN、FN、sensitivity、specificity、balanced accuracy、accuracy；优先呈现前四种，不单独用 accuracy 说明有效性。
- Brier score，明确是未校准输出的描述；可用少量分箱的可靠性图，但 16 个外部 SS 不支持精细亚组校准结论。
- 每 seed 的选择 epoch；三 seed 均值、sample SD 和配对差值；三 seed 不是三组独立临床样本。
- 多 bag 时逐切片 score SD、预测翻转比例、各 draw AUROC 分布、均概率预测。不要将 20 个 bag 当成临床样本量扩大 20 倍。
- 参数量、GPU wall time、峰值显存、推理成本。报告原型或统计分支是否存在，而不仅写模型简称。

AUROC 区间与方法差值建议使用 **10,000 次类别分层、逐切片配对 bootstrap**：每次同一批采样索引用于所有方法。固定 bootstrap RNG 并保存配置。Sensitivity、specificity、accuracy 使用 Wilson 区间。由于缺少患者映射，本文仅给切片层面条件区间，不伪造患者层面重采样。

阈值优化可作为独立次要分析：若实施，只用内部数据选阈值后原样迁移到外部，完整保留 0.5 的主比较。为避免把工作点调优误称算法提高，本轮不建议把阈值搜索加入主候选选择规则。

训练保存：


独立检查至少包括：

1. 清单中的 144 / 49 / 168 切片集合与历史基线一一对应、标签相同，无缺失或重复。
2. 同 seed 下各配置训练 bag 和 minibatch 顺序确实配对；内部固定评价 bag 未漂移。
3. 每个保存 checkpoint 的 epoch 等于 history 中“首次最高内部 AUROC”的 epoch。
4. 使用 CPU 或独立推理路径抽查 checkpoint，验证落盘预测；逐行重新计算指标与 confusion matrix。
5. 方案选择文件是在外部预测前生成，记录的赢家确实满足预定义排序规则。
6. 集成是三个指定 seed 的概率均值，逐切片核验；不得因某 seed 较差而排除。
7. 权重、逐例预测和汇总指标在所有图表中有统一模型身份；历史原模型数值不会被挪到新模型。
8. 原始 checkpoint、特征、v7 稿件不被新实验覆盖；新文件全部保存在本轮独立目录。

以下由 v7 已有 `experiments/controlled_training/all_predictions.csv` 直接计算，**不是新训练结果、不是本轮正式比较、不能用于宣称预先未知的外部收益**。三 seed 均为 17、29、43。

| matched attention | internal | 0.934783 | 0.004424 | 0.938127 | 0.913043 / 0.769231 |

## 9. 当前资源与完成边界

旧 9-run 受控训练记录约 185 秒，使用既有缓存特征；可据此估算简单候选的数量级，但双 bag、不同聚合器和大量重复推理会增加成本。建议先运行 B0/B1 完整三 seed 作为复现和计时，再给出本轮实际预计时间，而不按训练 epoch 数生硬保证时长。

本轮完成的标准是：冻结方案、全部运行、选定方案后的历史外部评价、独立核验、完整报告成功与未成功项。若没有候选稳定提升，应明确报告没有获得可复现的改进；这仍能指导是否需要更多 SS、临床资料或不同训练策略，但不要求为了获得更好数字继续挑 seed。
