\section*{Declarations}
\paragraph{Data availability.} Numeric Source Data accompany the manuscript as a separate archive. They comprise publication-coded slide-level model predictions, internal split labels, model and component summaries, interpretation-case outputs and acquisition metadata recovered from the WSI headers. Additional data include matched external comparator scores, repeated-bag outputs and exact indices, model-variable diagnostics, paired error summaries, ROI audit measurements, additional model-development results and two logistic controls. These include complete run outcomes, selection records and secondary aggregation analyses. Original slide filenames and filesystem paths are omitted from the coded prediction tables. The reader file contains provisional aggregate counts only. The contents and access status are summarized in Supplementary Table S8. \missing{[MISSING A04: confirm the institution-approved public release scope, repository identifier and access route for raw WSIs and clinical records.]} The accompanying draft archive is not a public repository deposit.

\paragraph{Code availability.} Archived custom training and external-inference source files, the main model configuration, the fixed-checkpoint, controlled-training and bounded-development protocols and runners, and metric/figure-generation scripts accompany the manuscript in a Source Code archive. File identities are documented by SHA-256 hashes. The archive records the implementation and retains the original script path configuration; it is not a newly validated portable training release. The new checkpoint analyses reproduced the available original reference scores and record their current runtime dependencies separately. Their input manifests require approved feature-file access; successful LaTeX compilation, statistical regeneration, checkpoint inference and complete training reproduction are distinct levels of reproducibility. TRIDENT is available from \url{https://github.com/mahmoodlab/TRIDENT}, and the UNI2-h model source is \url{https://huggingface.co/MahmoodLab/UNI2-h}. Foundation-model and trained-model weights are not redistributed in the draft archive. \missing{[MISSING A05: supply the author-controlled code repository, release licence and trained Hybrid weight-access arrangement.]}
